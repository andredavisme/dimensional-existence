Tables as Dimensions

Each table in a relational database represents a distinct dimension of existence. The number of rows maps to the cardinality of that dimension — analogous to the number of faces on a polyhedral die.

Foreign Keys as Dimensional Links

A foreign key connecting two tables is the schema equivalent of two dimensions interacting — what happens in one affects what is valid in the other. This mirrors how entangled quantum particles share state across dimensions.
