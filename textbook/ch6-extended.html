Adding Dimensions

Each new dimension added to the system — whether physical or schema-based — follows the same principle: it is expressed as a new table (or polyhedral axis) linked by a foreign key (or physical law). The same rules that govern d3 space govern every higher dimension.

The Schema as a Meta-Dimension

The schema itself — its ERD, migrations, and DDL — exists in 3D space and time. It describes all other dimensions while simultaneously being subject to them. This makes the schema a meta-dimension: a dimension that contains and constrains all others.
