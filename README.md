# Dimensional Existence

An interactive learning platform exploring dimensional theory through polyhedral models, relational schema design, and quantum mechanics.

**Live Site:** https://andredavisme.github.io/dimensional-existence/

## Structure

| Folder | Purpose |
|---|---|
| `/textbook` | Markdown chapters with resource links |
| `/simulators` | Interactive dimensional/polyhedral explorers |
| `/quizzes` | Quiz apps with Supabase-backed leaderboard |
| `/counter` | Page view counter |
| `/supabase` | Schema SQL and migration files |
